How to use

Pick a game. Takes about a minute.

The Forest SotF · Memory SotF · BepInEx Phasmophobia

Download the Forest loader and run it. Pick The Forest in the list on the left.

02

Launch The Forest and load a save.

03
Inject

Click inject. The menu loads straight into the running game.

Press INSERT in-game.

01
Download & run

Run the Forest loader and pick Sons of the Forest. Leave the mode on memory (default).

02
Start the game

Launch Sons of the Forest and load a save.

03
Attach

Click attach. Nothing is installed or written to the game folder.

04
Use the trainer

Open the trainer tab: shortcuts on the left, every dev command on the right. Type an argument if needed and click run, or double-click to run without one.

01
Switch mode

In the loader, pick Sons of the Forest and switch the mode to bepinex plugin.

02
Install

Close the game and click install. BepInEx 6 IL2CPP (be.755) is downloaded into the game folder.

03
First run only

BepInEx has to run the game once. Wait for the main menu (1–3 min), close the game, then click install again.

04
Play

Start the game, load a save and press INSERT. Uninstall removes the menu (BepInEx stays).

01
Download & run

Run the Phasmophobia loader. It asks for admin and puts a shortcut on your desktop.

02
Generate offsets

Only needed the first time and after a new Phasmophobia update. Download the offset files from Offsets, unzip them into a folder, click GENERATE OFFSETS in the loader and pick that folder. New files are posted here when the game updates.

03
Window mode

Set Phasmophobia to borderless or windowed — exclusive fullscreen hides overlays.

04
Launch

Click LAUNCH ESP, start a contract, disable the Safety lock in the MISC tab, and press INSERT for the menu.

// faq

Questions

Does it work online?

Yes. The Forest and Sons of the Forest support multiplayer without an online lock. Phasmophobia also supports multiplayer, but its Safety lock must be disabled in the MISC tab first.

Is it free?

Yes. No key, no account. Just download and run.

My antivirus flags the exe

New unsigned exe files often get flagged. That's a false positive — add an exception if Windows or your antivirus blocks it.

Why does it ask for admin?

The loaders read the game's memory, which needs admin rights on most PCs.

Phasmophobia boxes don't line up

Set MISC → FOV to your in-game FOV. If the boxes follow the wrong view, press F5 to switch camera.

The ESP stopped after a Phasmo update

The game's class names change every update. Download the new offset files from the Offsets section and run GENERATE OFFSETS again.

Fly doesn't work in The Forest

Open the movement tab and watch the debug box while flying. If "reset by game" keeps climbing, switch the fly method or the moved object.

Why are some SotF features missing?

Sons of the Forest is built differently (IL2CPP). Chams and time of day aren't in SotF yet, and memory mode only runs the game's own commands.

Game folder not found

Pick the game folder manually under settings in the Forest loader.

Exclusive fullscreen hides the overlay

Overlays can't draw over exclusive fullscreen. Set Phasmophobia to borderless or windowed.
